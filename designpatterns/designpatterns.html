Pattern 7 — Feature Sliced Design

Like a skyscraper blueprint — each layer has a purpose, built in order

APP — app wide settings, routing, providers
PAGES — full page components
WIDGETS — large reusable UI blocks
FEATURES — user interactions and flows
ENTITIES — business domain objects
SHARED — reusable utilities and UI primitives

⬆️ Higher layers depend on lower ones — never reverse
