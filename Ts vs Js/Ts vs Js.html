TypeScript vs JavaScript Demo

Same code — showing the difference between JS and TS

1. Dynamic vs Static Typing

JavaScript — No Types

// JS — no type defined
let age = 25;
age = "twenty five"; // allowed!
age = true; // also allowed!
// No error — anything goes

TypeScript — Types Defined

// TS — type defined as number
let age: number = 25;
age = "twenty five"; // ERROR!
age = true; // ERROR!
// TS catches this before running

2. Function Parameters

JavaScript

// JS — no type checking
function add(a, b) {
  return a + b;
}

add(5, 10);     // 15 ✅
add("5", 10);   // "510" ❌ bug!
add(5, "ten");  // "5ten" ❌ bug!

TypeScript

// TS — types enforced
function add(a: number, b: number) {
  return a + b;
}

add(5, 10);     // 15 ✅
add("5", 10);   // ERROR! ✅
add(5, "ten");  // ERROR! ✅

3. Interfaces (TypeScript Only)

JavaScript — No Interface

// JS — no structure enforced
function greetUser(user) {
  return "Hello " + user.name;
}

// Missing name? No error until runtime
greetUser({});  // "Hello undefined"
greetUser({ age: 20 }); // "Hello undefined"

TypeScript — Interface Defined

// TS — interface enforces structure
interface User {
  name: string;
  age: number;
}

function greetUser(user: User) {
  return "Hello " + user.name;
}
greetUser({});         // ERROR! ✅
greetUser({ age: 20 }); // ERROR! ✅
greetUser({ name: "John", age: 20 }); // ✅

4. Error Catching — Compile Time vs Runtime

JavaScript — Runtime Error

// JS — error only shows when code runs
let user = null;
console.log(user.name);
// Error: Cannot read property
// 'name' of null
// — shows up in production!

TypeScript — Compile Time Error

// TS — error caught before running
let user: User | null = null;
console.log(user.name);
// ERROR: Object is possibly null
// — caught during development!

5. Side by Side Summary

Feature JavaScript TypeScript
Typing Dynamic — no types needed Static — types required
Errors caught At runtime — after code runs At compile time — before code runs
Interfaces Not supported Fully supported
Browser Runs directly Must compile to JS first
Best for Small projects, beginners Large projects, teams
File extension .js .ts or .tsx
