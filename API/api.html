6. REST vs GraphQL — Data Fetching

REST — Gets Everything

GET /api/user/1
Returns ALL user data:
{
  id, name, email,
  phone, address,
  company, website...
}
Even data you don't need!

GraphQL — Gets Exactly What You Need

query {
  user(id: 1) {
    name
    email
  }
}
Returns ONLY:
{ name, email }
Nothing extra!
